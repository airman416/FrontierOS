# Frontier OS

Interactive 3D visualization of basketball athletic, nutritional, and technical development as a force-directed dependency graph. Built for Helm Labs demos with a mobile-first layout.

## Stack

Vite, React, TypeScript, Tailwind CSS, Zustand, Three.js, React Three Fiber, `@react-three/drei`, and `d3-force-3d`.

## Run locally

```bash
npm install
npm run dev
```

```bash
npm run build && npm run preview
```

## Remote

Create the GitHub repository at [github.com/airman416/frontier-os](https://github.com/airman416/frontier-os), then:

```bash
git branch -m main
git remote add origin https://github.com/airman416/frontier-os.git
git push -u origin main
```
